## 1. 产品概述

一个极简的个人记账应用——用户每天用一句话告诉应用"花了多少钱、用在哪里"，应用自动解析、归类并生成可视化汇总。目标是让记账像写一句话日记那样轻松自然，解决传统记账软件字段繁琐、难以坚持的问题。

- 目标用户：希望轻量记账、不想花时间填表单的个人用户
- 核心价值：一句话输入 → 自动分类 → 即时汇总，每天 5 秒完成记账

## 2. 核心功能

### 2.2 功能模块

1. **记账主页**：自然语言快速记账、今日概览卡片、近期交易时间线
2. **汇总分析页**：周/月维度切换、分类占比环形图、每日支出趋势柱状图

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 记账主页 | 自然语言输入框 | 输入"午餐35"或"打车花了12.5元"，自动解析金额与用途，匹配分类 |
| 记账主页 | 快捷分类标签 | 一键选择餐饮/交通/购物等常用分类，覆盖默认推断 |
| 记账主页 | 今日概览卡片 | 今日总支出、笔数、对比昨日增减 |
| 记账主页 | 近期交易时间线 | 按时间倒序展示最近交易，支持编辑分类、删除、修改金额 |
| 汇总分析页 | 维度切换器 | 在周/月/年之间切换汇总范围 |
| 汇总分析页 | 核心指标行 | 总支出、日均支出、最大单笔、记账天数 |
| 汇总分析页 | 分类占比环形图 | 各分类支出占比，点击查看该分类明细 |

## 3. 核心流程

用户在输入框输入一句话（如"午餐35"）→ 前端解析器提取金额与用途文本 → 关键词匹配推断分类 → 展示解析预览供用户确认/微调 → 确认后写入 localStorage → 今日概览与时间线即时刷新 → 汇总页基于全量数据计算。

```mermaid
    D --> E["确认写入本地存储"]

```

## 4. 用户界面设计

### 4.1 设计风格

- **美学方向**：温暖编辑风（Warm Editorial）——像一本精心装帧的个人财务手账，规避通用 AI 紫色渐变与扁平白底
- **主色调**：暖米/燕麦色背景（#F5F0E6 系），陶土赭石（#B5651D 系）作为支出强调色，鼠尾草绿（#6B8E6B 系）作为正向/辅助色，墨黑（#2A2622）用于正文
- **字体**：显示字体用衬线体 Fraunces（有手账质感），正文用无衬线 DM Sans，数字用等宽 JetBrains Mono 强化账目感
- **布局**：桌面端单列居中内容流 + 左侧固定导航；卡片式模块，柔和投影与细描边结合
- **图标**：线性极简图标 + 少量分类 emoji 点缀
- **动效**：输入解析时金额数字翻牌动画、时间线条目错峰淡入、环形图绘制动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-----------|-------------|
| 记账主页 | 自然语言输入框 | 居中大号输入框，陶土色聚焦描边，下方实时显示解析出的金额/用途/分类胶囊 |
| 记账主页 | 今日概览卡片 | 墨黑大号数字显示今日总额，右侧小字笔数与环比箭头 |
| 记账主页 | 近期交易时间线 | 左侧时间轴竖线，每条记录含分类色点、用途、金额（等宽字体右对齐） |
| 汇总分析页 | 核心指标行 | 四宫格指标卡，大数字 + 小标签 |
| 汇总分析页 | 分类占比环形图 | 自绘 SVG 环形图，中心显示总额，图例可交互 |
| 汇总分析页 | 每日趋势柱状图 | 自绘 SVG 柱状图，hover 显示 tooltip |

### 4.3 响应式

桌面优先（最大宽度 880px 居中内容流），移动端自适应单列堆叠，触摸优化按钮与输入框尺寸。
